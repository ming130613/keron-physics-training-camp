# 케론별 우주선 수리 작전

파동·전자기 유도·광학을 직접 조작하며 배우는 한국어 웹 학습 게임입니다.
대원을 선택하고 고장 난 우주선의 장치를 차례로 수리한 뒤, 지구 물리 탐사로 이어집니다.

## 주요 기능

- 대원 5명 선택 및 캐릭터별 능력 안내
- 파동 → 전자기 유도 → 광학 → 관제실 순차 해금
- 원리 발견 → 조건 비교 → 실제 수리의 단계별 실험
- 수리율·항로 위험도, 성공 일지 및 지구 도착 연출
- 지구 탐사의 관찰 → 예상 → 실험 → 발견 활동
- 작은 화면 대응, 키보드 조작 및 모션 감소 설정 지원

## 실행 방법

별도 빌드나 패키지 설치 없이 사용하는 HTML/CSS/JavaScript 프로젝트입니다.

1. 이 저장소를 다운로드하거나 복제합니다.
2. 폴더의 `index.html`을 최신 웹 브라우저로 엽니다.
3. 대원을 선택하고 화면 안내에 따라 수리 작전을 진행합니다.

로컬 서버를 사용하려면 Python이 설치된 환경에서 프로젝트 폴더에서 다음을 실행합니다.

```sh
python -m http.server 8000
```

브라우저에서 http://localhost:8000 을 엽니다.

## 미디어 리소스

원본 이미지 33개와 지구 도착 영상 1개를 `assets/`에 포함했습니다. 코드가 참조하는 이미지·영상 파일의 존재 여부를 확인했습니다. 이미지 로딩 실패 시 공통 대체 그림을 표시합니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 게임 화면과 대화상자 |
| `style.css` | 화면 스타일·반응형 배치·애니메이션 |
| `script.js` | 게임 진행·물리 실험·상태 관리 |
| `README.md` | 프로젝트 소개와 실행 안내 |
| `CHANGELOG.md` | 패치에 포함된 기존 README 원문과 업데이트 기록 |
| `assets/` | 캐릭터·배경·일지·응원 이미지와 지구 도착 영상 |

## 저장 데이터

선택한 캐릭터와 지구 탐사 상태는 브라우저의 `localStorage`를 사용합니다.
우주선 수리 진행도는 다시 접속하면 초기화됩니다.
브라우저의 사이트 데이터를 삭제하면 저장된 선택·탐사 기록도 초기화될 수 있습니다.

## 개발 메모

- 프레임워크와 백엔드 없이 동작하는 정적 웹 프로젝트입니다.
- 일부 글꼴은 Google Fonts를 참조하므로 네트워크 환경에 따라 대체 글꼴로 표시될 수 있습니다.
- 구버전 실험 코드를 제거하고, 저장소 접근 실패 대응과 누락 이미지 대체 처리를 분리했습니다.
- JavaScript 구문 검사를 지원합니다: `npm run check`. 전체 플레이 검증은 별도로 필요합니다.

상세 변경 이력은 [CHANGELOG.md](CHANGELOG.md)를 확인하세요.

## GitHub Pages 배포

1. 저장소 **Settings → Pages**를 엽니다.
2. Source를 **Deploy from a branch**로 선택합니다.
3. Branch는 **main**, 폴더는 **/(root)**로 선택하고 **Save**를 누릅니다.
4. Pages 배포 완료 후 https://ming130613.github.io/keron-physics-training-camp/ 에서 접속합니다.

별도 빌드 과정은 없습니다. 루트의 `.nojekyll`로 정적 파일을 그대로 배포합니다. 모든 리소스는 프로젝트 하위 경로에서 동작하는 상대 경로를 사용합니다. 이후 main 변경 사항은 Pages 설정에 따라 자동 반영됩니다.

### 코드 구성

- `runtime.js`: 저장소 접근 실패 시 메모리 대체, 누락 이미지 처리
- `script.js`: 화면 전환, 수리 미션, 지구 탐사
- `style.css`: 기본 화면과 수리 미션 스타일
- `styles/chapters.css`: 지구 탐사와 후속 화면 스타일 (기존 적용 순서 유지)
- `assets/placeholder.svg`: 누락 이미지 공통 대체 그림

원본 미디어를 포함하며, 이미지 로딩 실패에 대비한 대체 그림과 영상 건너뛰기 동작도 유지합니다.
