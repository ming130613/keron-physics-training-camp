# 케론별 우주선 수리 작전

파동·전자기 유도·광학을 직접 조작하며 배우는 한국어 웹 학습 게임입니다.
대원을 선택하고 고장 난 우주선의 장치를 차례로 수리한 뒤, 지구 물리 탐사로 이어집니다.

## 주요 기능

- 대원 5명 선택 및 캐릭터별 능력 안내
- 파동 → 전자기 유도 → 광학 → 관제실 순차 해금
- 원리 발견 → 조건 비교 → 실제 수리의 단계별 실험
- 수리율·항로 위험도, 성공 일지 및 지구 도착 연출
- 지구 탐사의 관찰 → 예상 → 실험 → 발견 활동
- 작은 화면 대응, 키보드 조작 및 모션 감소 설정 지원

## 실행 방법

별도 빌드나 패키지 설치 없이 사용하는 HTML/CSS/JavaScript 프로젝트입니다.

1. 이 저장소를 다운로드하거나 복제합니다.
2. 폴더의 `index.html`을 최신 웹 브라우저로 엽니다.
3. 대원을 선택하고 화면 안내에 따라 수리 작전을 진행합니다.

로컬 서버를 사용하려면 Python이 설치된 환경에서 프로젝트 폴더에서 다음을 실행합니다.

```sh
python -m http.server 8000
```

브라우저에서 http://localhost:8000 을 엽니다.

## 현재 업로드 상태: 이미지·영상 누락

이번에 제공된 업데이트 패치 폴더에는 `index.html`, `style.css`, `script.js`, 기존 `README.md`만 포함되어 있습니다.
코드가 참조하는 `assets/` 폴더는 제공되지 않아 이 저장소에도 아직 없습니다.
따라서 캐릭터·배경·일지 이미지와 도착 영상 등이 표시되지 않으며, 완전한 화면과 연출을 확인하려면 원본 미디어 파일을 추가해야 합니다.

원본 전체 배포본의 `assets/` 폴더를 저장소 루트에 그대로 추가하세요. 코드가 참조하는 파일명을 유지해야 합니다.
예: `assets/keroro.webp`, `assets/diary_intro.webp`, `assets/arrival_scene_1.webp`, `assets/earth_arrival_movie.mp4`.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 게임 화면과 대화상자 |
| `style.css` | 화면 스타일·반응형 배치·애니메이션 |
| `script.js` | 게임 진행·물리 실험·상태 관리 |
| `README.md` | 프로젝트 소개와 실행 안내 |
| `CHANGELOG.md` | 패치에 포함된 기존 README 원문과 업데이트 기록 |
| `assets/` | 이미지·영상 리소스 — 현재 미포함 |

## 저장 데이터

선택한 캐릭터와 지구 탐사 상태는 브라우저의 `localStorage`를 사용합니다.
우주선 수리 진행도는 다시 접속하면 초기화됩니다.
브라우저의 사이트 데이터를 삭제하면 저장된 선택·탐사 기록도 초기화될 수 있습니다.

## 개발 메모

- 프레임워크와 백엔드 없이 동작하는 정적 웹 프로젝트입니다.
- 일부 글꼴은 Google Fonts를 참조하므로 네트워크 환경에 따라 대체 글꼴로 표시될 수 있습니다.
- 이번 업로드에서는 원본 게임 코드의 기능을 변경하지 않았습니다.
- 자동 테스트 및 완전한 게임 플레이 검증은 아직 수행하지 않았습니다.

상세 변경 이력은 [CHANGELOG.md](CHANGELOG.md)를 확인하세요.
